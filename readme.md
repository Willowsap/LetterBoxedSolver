A simple program for solving the New York Times letterboxed game in two words.

1. git clone https://github.com/Willowsap/LetterBoxedSolver
2. cd LetterBoxedSolver
3. javac nyt/LetterBoxedApp.java
4. java nyt/LetterBoxedApp OR java nyt/LetterBoxedApp <path-to-file-containing-puzzle>

If a file containing the puzzle is used it should look like the following
abc
def
ghi
jkl
Where each line is the three letters of a side of the puzzle. Ordering of the sides does not matter.
